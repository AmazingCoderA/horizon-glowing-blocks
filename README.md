# Horizon mods / моды для Horizon

[English](#english) | [Русский](#русский)

## Русский

Минимальный **контент-мод** для [Horizon](https://github.com/horizon-rust/horizon) (Rust-переписывание Minecraft Java 26.3). Добавляет блок `glowing_amethyst`. Собран `cargo-horizon-mod`, лаунчер не нужен.

### Скачать

**v0.1.0+mc26.3** — [![Скачать .hmod](https://img.shields.io/badge/DOWNLOAD-HMOD-2ea44f)](https://github.com/AmazingCoderA/horizon-mods/releases/download/v0.1.0%2Bmc26.3/glowing_blocks-0.1.0%2Bmc26.3.hmod)

Установка: положить `.hmod` в папку игры `horizon-mods/`, добавить `mod.glowing_blocks:true` в `horizon-mods.txt`.

### Атрибуция

Основано на шаблоне [horizon-rust/horizon-native-mod-template](https://github.com/horizon-rust/horizon-native-mod-template) и генераторе контент-модов Horizon. Авторство — **Horizon Team** (Ludovic Marie и контрибьюторы). Лицензия MIT (`LICENSE`). **Раскрытие LLM:** сборка и документация подготовлены с помощью LLM (агент OpenCode). Это не официальный продукт Mojang/Microsoft.

**Важно:** это не композитор Waylandcraft. Порт композитора на API Horizon (`horizon-mixins`) не выполнен.

## English

A minimal **content mod** for [Horizon](https://github.com/horizon-rust/horizon), the Rust rewrite of Minecraft Java 26.3. Adds one `glowing_amethyst` block. Built with `cargo-horizon-mod`; no launcher required.

### Download

**v0.1.0+mc26.3** — [![Download .hmod](https://img.shields.io/badge/DOWNLOAD-HMOD-2ea44f)](https://github.com/AmazingCoderA/horizon-mods/releases/download/v0.1.0%2Bmc26.3/glowing_blocks-0.1.0%2Bmc26.3.hmod)

Install: copy the `.hmod` into the game folder's `horizon-mods/` and add `mod.glowing_blocks:true` to `horizon-mods.txt`.
